# Dynamic Island для Android

Нативное приложение (Kotlin, без внешних зависимостей). Рисует остров поверх статус-бара,
сам находит камеру через `DisplayCutout` и растёт из неё: слева / по центру / справа;
если выреза нет (камера под экраном или на рамке) — виртуальный остров по центру, как на iPhone.

Показывает: сообщения, музыку (с управлением), звонки (принять/сбросить), зарядку.
Анимации — пружинная физика на каждом крае формы + blur/scale-переходы содержимого.

Сборка: `ANDROID_HOME=/path/to/sdk ./gradlew assembleRelease` → `app/build/outputs/apk/release/`.
Готовый APK: `DynamicIsland.apk`.

Разрешения: «Поверх других окон», «Доступ к уведомлениям», «Показ уведомлений» (Android 13+).
