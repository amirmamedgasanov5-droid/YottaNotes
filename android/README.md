# TV Desk — планшет → ТВ по USB-C + клавиатура и тачпад

Нативное Android-приложение (Kotlin, без сторонних библиотек). Android 11+.

## Что делает
- **Вывод на ТВ**: кнопка «Вывести экран на ТВ» — картинка экрана планшета идёт на телевизор,
  подключённый по USB-C (DisplayPort Alt Mode / USB-C→HDMI).
- **Панель на планшете**: полная клавиатура (F1–F12, Esc, Tab, Caps, Shift, Ctrl, Win, Alt, стрелки,
  Home/End/PgUp/PgDn, EN/RU) + тачпад (курсор, тап, перетаскивание, прокрутка двумя пальцами,
  ЛКМ/ПКМ) + кнопки Назад/Домой/Задачи. Звук и вибро клавиш — по желанию.
- **На ТВ панели нет**: картинка на ТВ обрезается до области над панелью, а сама панель помечена
  FLAG_SECURE (не попадает ни в захват, ни в системное зеркалирование).

## Установка
1. Установить `app-debug.apk` (или скачать из GitHub Actions → Artifacts → `tvdesk-apk`).
2. Открыть TV Desk, пройти 3 шага: «поверх окон», служба доступности, клавиатура TV Desk.
   (Android 13+: если служба доступности серая — «Данные приложения» → ⋮ → «Разрешить ограниченные настройки».)
3. «Включить панель» и «Вывести экран на ТВ» (в окне Android выбрать «Весь экран»).

## Как устроено
| Часть | Реализация |
|---|---|
| Картинка на ТВ | `MediaProjection` → `VirtualDisplay` → `TextureView` в `Presentation` на внешнем дисплее |
| Клавиши, Ctrl+C/V/… | своя `InputMethodService`: `sendKeyEvent` с META-флагами в поле ввода |
| Курсор, клик, прокрутка, drag | `AccessibilityService.dispatchGesture` + курсор в `TYPE_ACCESSIBILITY_OVERLAY` |
| Панель | оверлей `TYPE_ACCESSIBILITY_OVERLAY`, не берёт фокус (поле ввода остаётся активным) |

## Ограничения (честно)
- ТВ должен определяться как **отдельный дисплей**. Если планшет сам зеркалит экран на уровне системы
  (нет отдельного дисплея), окно на ТВ не создать — но панель всё равно скрыта через FLAG_SECURE.
- Клавиши работают, пока в каком-то приложении **активно поле ввода** (клавиатура Android так устроена).
  Глобальные сочетания вроде Alt+Tab без поля ввода недоступны.
- Нельзя перекрыть чужие окна: приложения не «сдвигаются» над панелью, поэтому низ экрана под панелью не виден.
  Панель можно перенести наверх или свернуть.
- Правый клик = долгое нажатие (в Android нет правой кнопки для касаний).
