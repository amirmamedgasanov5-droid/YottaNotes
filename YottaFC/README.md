# YOTTA FC 26 — нативная футбольная игра для Android

Полноценный футбольный симулятор на чистом Android SDK (Java, без движков и ассетов — всё рисуется и звучит процедурно).

**Установка:** скопируйте `YottaFC26.apk` на телефон и откройте (разрешите установку из неизвестных источников).

## Что внутри
- Матч 11×11 в 2.5D (настоящая перспективная камера), анимированные футболисты, судья, два помощника, тренеры, трибуны, реклама, ворота с сеткой, день/вечер/ночь, дождь
- Правила: офсайд (флажок помощника), фолы, жёлтые/красные карточки, штрафные со стенкой, пенальти, угловые, ауты, вбрасывания, травмы, замены (5), добавленное время, доп. время и серия пенальти в кубке
- Управление: плавающий стик, УДАР (удержание — сила), ПАС, ПРОРЕЗ, НАВЕС, БЕГ; в обороне ОТБОР/ПОДКАТ/СМЕНА/ПРЕСС
- ИИ: прессинг, укрывающие, подстраховка, забегания, офсайдная линия, вратарь с нырками, 4 уровня сложности
- Повторы голов, статистика, оценки игроков, лучший игрок
- Карьера: 16 клубов, лига (30 туров) + кубок, трансферные окна, покупка/продажа/свободные агенты, предложения за игроков, финансы, развитие клуба, возраст/прогресс/травмы/дисквалификации, 9 схем и тактика, сохранения
- Быстрый матч и серия пенальти

## Сборка
`./build.sh` (aapt, dx, zipalign, apksigner, JDK) → `build/YottaFC26.apk`. Также есть Gradle-проект для Android Studio.
